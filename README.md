# Fragments UI

This is the front-end web application for the Fragments project. It allows users to sign in with Amazon Cognito Hosted UI and interact with the Fragments API server.

## Features

- Sign in using Amazon Cognito Hosted UI
- Display authenticated user information
- Create a text fragment
- Send HTTP requests to the Fragments API
- Show API responses in the browser and DevTools

## Technologies Used

- HTML
- CSS
- JavaScript
- Parcel
- Amazon Cognito
- Fetch API
